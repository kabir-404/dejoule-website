
## Stack

- **Next.js 16.2.6** — App Router only. Turbopack is the default bundler for both dev and build.
- **React 19.2.4** — includes View Transitions, `useEffectEvent`, Activity component.
- **TypeScript 5** with strict mode and `@/*` path alias resolving to the repo root.
- **Tailwind CSS v4** — configured via `@tailwindcss/postcss` PostCSS plugin. Uses `@import "tailwindcss"` and `@theme inline {}` in CSS (not `@tailwind base/components/utilities`).

## Next.js 16 Breaking Changes

**Before writing any code**, read the relevant guide in `node_modules/next/dist/docs/`. The version 16 upgrade guide is at `node_modules/next/dist/docs/01-app/02-guides/upgrading/version-16.md`.

### Async Request APIs (fully breaking)

`cookies()`, `headers()`, `draftMode()`, route `params`, and page `searchParams` are **all async** — synchronous access was removed. Always `await` them:

```tsx
export default async function Page({ params, searchParams }) {
  const { slug } = await params
  const query = await searchParams
  // ...
}
```

Use `PageProps<'/blog/[slug]'>`, `LayoutProps`, `RouteContext` helpers (generated by `npx next typegen`) for type-safe props.

### Routing: `proxy` replaces `middleware`

`middleware.ts` is deprecated. Use `proxy.ts` with a named `proxy` export:

```ts
// proxy.ts
export function proxy(request: Request) { /* ... */ }
```

Config flags renamed: `skipMiddlewareUrlNormalize` → `skipProxyUrlNormalize`. The `edge` runtime is **not** supported in `proxy`; keep `middleware.ts` if you need edge runtime.

### Linting

`next lint` is removed. Run `eslint` directly (the script in `package.json` is already `"lint": "eslint"`). ESLint uses flat config (`eslint.config.mjs`); do not create `.eslintrc` files.

### Caching — `use cache` directive

PPR and `experimental.dynamicIO` are replaced by `cacheComponents: true` in `next.config.ts`. Enable it to use the `'use cache'` directive at file, component, or function level.

Key rules for `use cache`:
- Cannot call `cookies()`, `headers()`, `searchParams` inside — read them outside and pass as arguments.
- Import `cacheLife` and `cacheTag` from `next/cache` (no longer prefixed with `unstable_`).
- `revalidateTag(tag, profile)` now requires a second `cacheLife` profile argument.
- Use `updateTag(tag)` in Server Actions for immediate (read-your-writes) invalidation.

### Parallel Routes

All parallel route slots require an explicit `default.js` file. Builds fail without them.

### `next/image` defaults changed

- `minimumCacheTTL` default: 60s → 14400s (4 hours)
- `imageSizes` default: `16` removed from array
- `qualities` default: locked to `[75]`
- Local images with query strings need `images.localPatterns.search` config
- `images.domains` is deprecated — use `images.remotePatterns`
- `next/legacy/image` is deprecated — use `next/image`

### Removed APIs

- `serverRuntimeConfig` / `publicRuntimeConfig` — use `process.env` in Server Components, or `NEXT_PUBLIC_` prefix for client-side values.
- AMP support (`next/amp`, `useAmp`, `amp` config key) — fully removed.
- `devIndicators` options: `appIsrStatus`, `buildActivity`, `buildActivityPosition`.
- `experimental.dynamicIO` — replaced by `cacheComponents`.

## Architecture

The `app/` directory uses the App Router with a single root layout (`app/layout.tsx`) that loads Geist Sans and Geist Mono via `next/font/google` and sets CSS variables consumed by Tailwind's `@theme inline` block in `globals.css`.

Turbopack config (when needed) goes at the top level of `NextConfig` as `turbopack: {}`, not under `experimental`.
